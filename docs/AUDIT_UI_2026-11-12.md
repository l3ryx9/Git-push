# Audit et refonte de l'interface — Git-Push

Date : 12 novembre 2026 · Base : version corrigée de l'audit de sécurité (passe P0).

## Limite à connaître

Aucun écran n'a pu être affiché dans l'environnement de travail (pas de `node_modules`, pas d'émulateur). Les choix ci-dessous sont vérifiés par le code, les calculs de contraste et des tests automatisés ; **le rendu réel reste à juger sur appareil**.

## 2. Direction artistique : « Terminal de nuit »

- **Une couleur = un sens.** Vert : action et état actif. Cyan : données Git (graphe). Violet : IA. Rouge : destruction. Le vert néon isolé de la progression est remplacé par l'accent de l'app.
- **Identité Matrix concentrée** sur la progression du push et le monospace des identifiants Git ; plus de décor répété sur les cartes.
- **Typographie** : Inter (déjà chargée, aucune dépendance ajoutée), 8 rôles, plancher 11 pt, casse de phrase.
- **Hiérarchie par l'arrondi** : pastilles 6-10, champs et boutons 14, cartes 18, feuilles et modales 24.
- **Thème sombre uniquement**, par choix : pas de thème clair.
- **Boutons vifs** : vert principal #00e865 (texte foncé, 11,5:1), rouge destructif plein #e3121f (texte blanc, 4,8:1).

## 3. Design system

`constants/theme.ts` : `space`, `radius`, `font`, `typography` (caption, label, body, bodyStrong, title, headline, display, code), `touch` (44 / 48), `motion`, `stateOpacity`, `readableSize`.
`constants/colors.ts` : ajout de `destructiveSolid` (#e3121f, 4,8:1 avec du blanc) et `aiForeground` (#0d0828, 7:1 sur le violet).

## 7. Limites restantes

- Rendu visuel à valider sur téléphone (petits écrans 360 dp, grande police système, TalkBack).
- Les écrans utilisent encore des tailles et marges en dur (environ 300 occurrences) : elles respectent le plancher mais ne passent pas toutes par les jetons. Migration progressive conseillée.
- Les confirmations destructives restent des boîtes de dialogue système (choix volontaire : comportement natif et accessible).
